# 课记 · 个人课时记录

这是一个无需账号、面向 iPhone 的轻量 PWA。界面只有四个入口：学生、课表、今天、设置。

- **学生**：添加或删除学生，按年手动添加 `10.11` 这样的上课日期；支持同一天多节课、删除单次或清空本年。
- **课表**：单独维护每周固定的学生、星期、时间、时长。
- **今天**：可选日期，查看固定课及临时安排；手动添加、编辑或移除当天的安排，不修改周课表；点「记为已上课」才手动计入学生记录。
- **设置**：自动生成课时默认关闭；如开启，只有打开当天或过去日期，且固定课程已经结束时才可能自动记入课时。手动删除后不会再自动补回。支持导出、恢复完整 JSON 备份。

### GitHub Pages 发布（iPhone Safari）

1. 在 GitHub 建立一个新的仓库（建议 `keji`），上传解压后的项目文件到仓库根目录，不要直接上传 ZIP。
2. Settings → Pages → Source: Deploy from a branch → `main` → `/ (root)` → Save。
3. 等待部署完成，使用 Safari 打开 `https://你的用户名.github.io/仓库名/`。
4. Safari 分享菜单 → 添加到主屏幕。

### 注意

数据保存在当前浏览器或主屏幕 Web App 的 `localStorage`，没有云同步；Safari 和主屏幕 App 也可能具有独立存储。**请定期在设置中导出备份，不要仅依赖手机本地存储。**

现阶段不支持真实的 Apple Pencil 自由手写，仅支持触屏键盘输入与编辑。
